# Retail Sales and Profit Analytics Dashboard

A Power BI project developed to analyze retail sales and profit data and present key business insights through an interactive dashboard.

## Tools Used

* Power BI
* Power Query
* DAX
* Excel

## Features

* Sales and profit analysis
* Product and store performance analysis
* Regional performance comparison
* KPI tracking
* Interactive charts and visualizations
* Business trend analysis

## Project Process

The data was cleaned and transformed using **Power Query**. DAX measures and KPIs were created to analyze sales, profit, products, stores, and regions. The final dashboard provides an easy-to-understand view of overall retail performance.

## Skills Demonstrated

* Data Cleaning
* Data Transformation
* Power BI
* Power Query
* DAX
* KPI Analysis
* Data Visualization
* Business Analytics
